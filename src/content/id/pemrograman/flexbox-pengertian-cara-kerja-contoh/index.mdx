## Apa Itu Flexbox?

Pernah merasa kesulitan menyusun elemen HTML agar sejajar dengan rapi? Misalnya ingin membuat menu navigasi, deretan kartu (*card*), atau menempatkan teks dan gambar berdampingan tanpa harus mengatur posisi satu per satu. Kalau pernah, tenang saja, kamu tidak sendirian, hehe. Nah, di sinilah **Flexbox** hadir sebagai solusi.

**Flexbox** (*Flexible Box Layout*) adalah salah satu metode layout pada CSS yang dirancang untuk mengatur posisi dan susunan elemen di dalam sebuah container agar lebih rapi, fleksibel, dan mudah dikelola. Dengan Flexbox, kita dapat menyusun elemen secara horizontal maupun vertikal tanpa lagi bergantung pada teknik layout lama seperti **float** atau pengaturan posisi yang rumit.

Untuk mulai menggunakan Flexbox, kita hanya perlu menambahkan properti berikut pada elemen yang ingin dijadikan container:

```css
display: flex;
```

Setelah properti tersebut diterapkan, elemen tersebut akan berubah menjadi **flex container**, sedangkan seluruh elemen di dalamnya otomatis menjadi **flex items**. Dari sinilah berbagai kemampuan Flexbox mulai bisa dimanfaatkan, mulai dari mengatur arah susunan elemen, posisi, jarak antar elemen, hingga bagaimana setiap elemen menyesuaikan ukurannya di dalam container.

Salah satu alasan mengapa Flexbox begitu populer adalah karena mampu menyederhanakan banyak pekerjaan yang sebelumnya cukup merepotkan. Hal-hal seperti membuat menu navigasi yang rapi, menempatkan konten tepat di tengah halaman, atau menyusun beberapa elemen dengan jarak yang konsisten kini dapat dilakukan hanya dengan beberapa baris CSS.

Bahkan, jika kamu menggunakan framework seperti **Tailwind CSS**, sebenarnya kamu sudah menggunakan konsep Flexbox tanpa disadari. Utility class seperti `flex`, `justify-center`, `items-center`, hingga `gap-*` semuanya bekerja di atas fondasi Flexbox. Karena itu, memahami dasar-dasar Flexbox akan membuatmu jauh lebih mudah mempelajari Tailwind CSS maupun teknik layout modern lainnya.

## Mengapa Menggunakan Flexbox?

Kalau kamu baru belajar membuat website, mungkin Flexbox terlihat seperti satu fitur CSS biasa. Padahal, sebelum Flexbox hadir, mengatur tata letak halaman web sering kali menjadi pekerjaan yang cukup melelahkan.

Dulu, banyak pengembang mengandalkan teknik seperti `float`, `inline-block`, bahkan **table layout** hanya untuk membuat beberapa elemen sejajar. Cara-cara tersebut memang bisa digunakan, tetapi sering kali membutuhkan banyak kode tambahan dan cukup sulit dikelola ketika tampilan website mulai berkembang.

Flexbox hadir untuk menyelesaikan masalah tersebut. Dengan beberapa properti CSS saja, kita sudah bisa mengatur arah susunan elemen, memusatkan konten, memberikan jarak yang konsisten, hingga membuat layout lebih mudah beradaptasi dengan berbagai ukuran layar. Hasilnya, proses membuat tampilan website menjadi jauh lebih sederhana sekaligus lebih nyaman untuk dikelola.

Beberapa alasan mengapa banyak developer memilih menggunakan Flexbox antara lain:

* Menyusun elemen secara horizontal maupun vertikal dengan lebih mudah.
* Memusatkan elemen tanpa perlu menggunakan teknik yang rumit.
* Mengatur jarak antar elemen secara konsisten menggunakan properti `gap`.
* Membuat layout yang lebih fleksibel dan mudah disesuaikan pada berbagai ukuran layar.
* Mengurangi jumlah kode CSS dibandingkan teknik layout yang lebih lama.

Tidak heran jika Flexbox kini menjadi salah satu fondasi dalam pengembangan website modern. Bahkan, banyak framework CSS seperti **Tailwind CSS** membangun berbagai utility class-nya di atas konsep Flexbox. Jadi, semakin memahami Flexbox, semakin mudah pula kamu mempelajari teknik layout modern lainnya.

## Cara Kerja Flexbox

Flexbox bekerja menggunakan dua konsep utama, yaitu **flex container** dan **flex items**. Memahami kedua istilah ini adalah langkah pertama sebelum mempelajari berbagai properti Flexbox.

Bayangkan sebuah rak buku. Rak tersebut berfungsi sebagai tempat untuk menyusun buku-buku di dalamnya. Dalam Flexbox, **rak** berperan sebagai **flex container**, sedangkan **buku-buku** yang berada di atasnya merupakan **flex items**. Kita tidak perlu mengatur posisi setiap buku satu per satu. Cukup atur raknya, maka seluruh buku akan tersusun mengikuti aturan yang telah ditentukan. Enak, kan? Kita jadi tidak perlu memindahkan "bukunya" satu per satu, hehe.

Misalnya kita memiliki struktur HTML seperti berikut:

```html id="x4y2kd"
<div class="container">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
</div>
```

Agar elemen tersebut menggunakan Flexbox, kita cukup memberikan properti `display: flex` pada container.

```css id="2ks8fa"
.container {
    display: flex;
    background-color: #f3f4f6;
    padding: 16px;
}

.item {
    background-color: #3b82f6;
    color: white;
    padding: 12px 20px;
}
```

Setelah `display: flex` diterapkan, elemen `.container` berubah menjadi **flex container**, sementara seluruh elemen di dalamnya otomatis menjadi **flex items**. Secara bawaan, browser akan menyusun semua item dalam satu baris dari kiri ke kanan.

Tentu saja, susunan tersebut bukanlah aturan yang harus selalu digunakan. Nantinya kita bisa mengubah arah penyusunan, mengatur posisi, memberikan jarak antar elemen, hingga menentukan bagaimana setiap item menyesuaikan ruang yang tersedia menggunakan berbagai properti seperti `flex-direction`, `justify-content`, dan `align-items`.

Inilah salah satu alasan mengapa Flexbox terasa begitu praktis. Kita tidak perlu mengatur posisi setiap elemen secara manual. Cukup tentukan aturan pada **flex container**, maka seluruh **flex items** di dalamnya akan mengikuti pengaturan tersebut secara otomatis. Pendekatan inilah yang membuat Flexbox jauh lebih sederhana, efisien, dan nyaman digunakan dibandingkan teknik layout CSS yang lebih lama.

## Properti Flexbox yang Paling Sering Digunakan

Flexbox sebenarnya menyediakan cukup banyak properti untuk mengatur tata letak elemen. Kabar baiknya, kamu tidak perlu menghafal semuanya sekaligus. Dalam praktik sehari-hari, hanya beberapa properti yang paling sering digunakan, dan kombinasi dari properti-properti inilah yang biasanya sudah cukup untuk membuat berbagai layout modern.

Mulai dari **navbar**, **card**, **hero section**, hingga berbagai tampilan responsif lainnya, sebagian besar dapat dibuat hanya dengan menggunakan properti berikut.

### `display: flex`

Properti ini merupakan langkah awal untuk menggunakan Flexbox. Ketika diterapkan pada sebuah elemen, elemen tersebut akan berubah menjadi **flex container**, sedangkan seluruh elemen di dalamnya otomatis menjadi **flex items**.

### `flex-direction`

Digunakan untuk menentukan arah penyusunan item di dalam container.

* `row` → item disusun dari kiri ke kanan (nilai bawaan).
* `column` → item disusun dari atas ke bawah.

### `justify-content`

Properti ini mengatur posisi item pada **sumbu utama (*main axis*)**.

Dengan `justify-content`, kita dapat membuat item rata kiri, berada di tengah, rata kanan, atau bahkan memberikan jarak yang merata di antara setiap item.

### `align-items`

Jika `justify-content` bekerja pada **main axis**, maka `align-items` mengatur posisi item pada **sumbu silang (*cross axis*)**.

Properti ini sering digunakan untuk membuat seluruh item berada tepat di tengah secara vertikal, terutama pada navbar atau tombol.

### `gap`

Digunakan untuk memberikan jarak antar **flex items** tanpa perlu menambahkan `margin` pada setiap elemen. Selain membuat kode lebih ringkas, penggunaan `gap` juga membuat layout lebih mudah dirawat ketika jumlah item berubah.

Sebagai contoh, berikut kombinasi beberapa properti Flexbox yang paling sering digunakan:

```css id="r8m4cs"
.container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
}
```

Pada contoh di atas:

* `display: flex` mengubah `.container` menjadi **flex container**.
* `justify-content: space-between` membuat item pertama berada di sisi kiri dan item terakhir di sisi kanan, sementara item lainnya tersebar secara merata di antaranya.
* `align-items: center` membuat seluruh item sejajar di tengah pada sumbu silang.
* `gap: 16px` memberikan jarak antar item sebesar **16 piksel**.

Keempat properti tersebut merupakan kombinasi yang paling sering dijumpai dalam pengembangan website modern. Setelah menguasainya, kamu sudah bisa membuat sebagian besar layout menggunakan Flexbox dengan jauh lebih mudah.

## Contoh Sederhana Flexbox

Sekarang kita masuk ke bagian yang paling seru, yaitu mencoba Flexbox secara langsung. Teori memang penting, tapi menurut Airi, belajar sambil mencoba itu jauh lebih cepat dipahami, hehe. Setelah memahami konsep dasarnya, kamu akan melihat bahwa Flexbox sebenarnya sangat mudah digunakan.

Pada contoh berikut, kita akan membuat tiga buah kotak yang tersusun dalam satu baris. Seluruh kotak akan berada di tengah secara vertikal, sementara jarak antar kotak diatur secara otomatis menggunakan properti `gap`.

```html id="t7k9wd"
<div class="container">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
</div>
```

Kemudian, tambahkan CSS berikut.

```css id="u4j2hz"
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 16px;
    padding: 20px;
    background-color: #f3f4f6;
}

.item {
    padding: 12px 20px;
    background-color: #3b82f6;
    color: white;
    border-radius: 8px;
}
```

Mari kita lihat apa yang terjadi:

* `display: flex` mengubah `.container` menjadi **flex container**.
* `justify-content: center` membuat seluruh item berada di tengah pada sumbu utama.
* `align-items: center` membuat semua item sejajar di tengah pada sumbu silang.
* `gap: 16px` memberikan jarak yang sama antar setiap kotak.

Hasilnya, ketiga elemen akan tersusun rapi dalam satu baris dengan jarak yang konsisten. Menariknya, kita tidak perlu menggunakan `float`, menghitung posisi secara manual, ataupun menambahkan `margin` pada setiap elemen. Semua pengaturan tersebut cukup dilakukan melalui **flex container**, sehingga kode menjadi lebih sederhana dan mudah dipelajari.

## Kesimpulan

Kalau di awal artikel Flexbox terdengar seperti sesuatu yang rumit, semoga sekarang rasanya sudah tidak sesulit itu.

Flexbox pada dasarnya hanyalah sebuah cara agar kita bisa menyusun elemen di halaman web dengan lebih mudah, lebih rapi, dan jauh lebih fleksibel. Dengan memahami konsep **flex container** dan **flex items**, lalu mengenal beberapa properti penting seperti `justify-content`, `align-items`, dan `gap`, kamu sudah memiliki bekal untuk membuat berbagai layout modern tanpa harus bergantung pada teknik CSS yang lebih rumit.

Namun, cara terbaik untuk benar-benar memahami Flexbox bukanlah dengan menghafal semua propertinya, melainkan dengan mencobanya secara langsung. Ubah nilai `justify-content`, coba ganti `flex-direction`, atau bereksperimen dengan `gap`. Semakin sering kamu mencoba, semakin mudah pula kamu memahami bagaimana setiap properti bekerja.

Setelah mulai terbiasa menggunakan Flexbox, kamu bisa melangkah ke materi berikutnya seperti **CSS Grid**, atau langsung mempraktikkannya pada proyek nyata, misalnya membuat **navbar**, **hero section**, **dashboard**, atau berbagai komponen antarmuka lainnya.
