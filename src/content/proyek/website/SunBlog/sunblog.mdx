## Tentang Proyek

SunBlog adalah proyek blog pribadi yang saya kembangkan untuk mendokumentasikan perjalanan belajar saya di dunia teknologi, khususnya pengembangan web. Proyek ini dibangun dari awal menggunakan [Astro](https://astro.build/) sebagai kerangka utama karena performanya yang luar biasa dalam menghasilkan situs statis yang cepat.

## Fitur Utama

- **Performa Cepat**: Dibangun dengan arsitektur Astro Islands, sebagian besar situs dikirim sebagai HTML statis, dengan JavaScript hanya dimuat untuk komponen interaktif.
- **Styling dengan Tailwind CSS**: Desain yang responsif dan modern diimplementasikan menggunakan Tailwind CSS, memungkinkan kustomisasi yang cepat dan konsisten.
- **Konten dengan MDX**: Artikel dan halaman ditulis dalam format MDX, memberikan fleksibilitas untuk menyisipkan komponen React langsung di dalam konten Markdown.
- **SEO-Friendly**: Dilengkapi dengan metadata yang kaya, sitemap, dan skema data terstruktur untuk visibilitas maksimal di mesin pencari.
- **Fitur Blog Lengkap**: Termasuk kategori, tag, daftar isi, artikel terkait, dan pencarian artikel.

## Teknologi yang Digunakan

- **Framework**: Astro
- **UI Library**: React (untuk komponen interaktif)
- **Styling**: Tailwind CSS
- **Konten**: MDX (Markdown with JSX)
- **Deployment**: GitHub Pages via GitHub Actions
